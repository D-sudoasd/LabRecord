# LabRecord 0.7.1 本地交付检查

日期：2026-10-25。范围：LabRecord 主应用的日常录入与查找。LabRecord-data 私人数据仓库未修改。

## 用户可见的改进

- 新建实验自动建议当天尚未使用的编号。同日再次新建时使用 `-02`、`-03` 等后缀，仍可手动修改。重复编号即时提示，提交前定位到编号输入框；主进程继续负责最终校验。
- 添加样品时，关闭或 Escape 会检查本次未保存的输入。“继续填写”或再次 Escape 保留输入，“放弃填写”才关闭。空白初始表单直接关闭。成功连续添加后，沿用的参数视为新表单起点，只有新的修改才触发提醒。
- 长按 Ctrl+Enter 或中文输入法组合输入不重复添加样品。提交结果不确定时继续复用原请求，保持既有幂等重试和重新读取结果的路径。
- 全库搜索提供清除按钮，恢复全部实验及输入焦点；方向键与回车继续可用，无结果时提示如何返回列表。
- 欢迎页说明演示实验会保存在本机实验库。

样品填写保护仅适用于当前弹窗，未保存内容不落盘，退出或崩溃后不恢复。数据库与备份格式仍为 v1；本轮不修改开始快照、原始时间、样品计数或云同步协议。

## 基线发现与处理

改动前的 137 项桌面检查中，136 项通过，1 项窄窗口回看断言失败。该测试将“待核对”筛选区滚动到视口中间，却检查下方表格首行的位置；两者之间的待核对清单可以占用较多高度。

本轮只修正这项测试的滚动目标：等待进入窄窗口布局，滚到实际检查的单元格并验证其位于视口，再保留原有横向滚动与首列固定断言。相关生产布局没有为测试放宽。失败日志和 trace 保存在 `local_artifacts/usability-baseline-desktop.log`、`local_artifacts/usability-baseline-review/`。

本轮开发版首次完整回归还有 7 项测试预期需要更新：6 项用宽泛标签查找搜索输入框，新增的清除按钮也被匹配；改为精确定位 combobox。1 项仍预期编辑过的样品表单按 Escape 后立即丢弃；现明确选择“放弃填写”再检查焦点返回。原有的数据与状态断言保留，7 项单独复跑全部通过，日志为 `local_artifacts/usability-regressions.log`。

构建工具为 Node.js 25.2.1；打包程序为 Electron 44.5.1 / Node.js 24.21.0 / Windows x64。实际打包运行路径和版本由 `runtime.json` 记录并由交付脚本核验。
