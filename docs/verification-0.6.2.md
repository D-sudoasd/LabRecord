# 0.6.2 工作区易用性验证

日期：2026-10-13（Asia/Shanghai）。基于远端 main 的 `ebf1396` 完成改进；测试使用合成实验及独立临时目录，没有读取或修改用户实验资料库。

## 需求与取舍

依据现有使用说明、材料准备模型和现场记录流程，按以下使用习惯优化：连续添加样品时先处理名称与数量；实验进行中会切换页面或查看另一实验；结束后按缺项逐条核对。这些是从产品现状推导的设计假设，未进行新的用户访谈或宣称测得操作效率提升。

- 规划统计合并为紧凑信息栏，减少首屏装饰空间。准备量、不同样品、计划操作、备样以及未知组数仍独立显示。
- 新增样品先填写数量与尺寸，材料制备字段继续展开并保留原值。未增加录入步骤或配置项。
- 规划和回看页显示全库进行中的操作，返回前先保存输入。失败时留在原页；导航不写入开始或结束时间。
- 队列显示状态数量，可找出跳过和中断项；搜索无匹配时可一起清除筛选。完整队列决定下一待测项。
- 回看可组合筛选时间不完整、文件未关联、未处理问题；无匹配与无计划分别提示。未开始的计划不计入缺少实际记录。实际文件栏不再把预期文件夹名当作已关联文件。
- 窄窗口回看表可横向滚动，并固定样品编号列。沿用现有中文字体、绿色主色和键盘焦点，未增加依赖。

## 检查结果

- 类型检查通过，生产构建通过。
- 原有 69 项单元测试通过；新增 1 项缺项筛选测试通过，覆盖 run 关联问题、未关联问题、已处理问题、未开始计划与实际引用。
- 原有 46 个桌面场景完成验证：首次 45 项通过，1 项因 Chromium 将整分钟的 datetime-local 值省略秒数而触发 Playwright 的严格填值检查；修正测试值的规范化后定向重跑通过。未修改实际时间处理逻辑。首轮失败证据保存在 `local_artifacts/usability-desktop`。
- 新增 3 个真实 Electron 场景通过：跨实验返回及保存失败；跳过/中断与清空筛选不改队列；缺项筛选、预期/实际区分、900 × 700 请求窗口在 150% 应用缩放下无页面横向溢出且样品列保持固定。
- Windows x64 打包程序 49 / 49 项场景全部通过，无跳过、失败或重试通过。确认实际运行版本为 0.6.2、Electron 44.5.1、Node 24.21.0、SQLite 3.53.4。
- ZIP CRC 校验通过；149 个归档文件中，程序、app.asar、帮助、示例表和运行资源等 10 个关键文件的 SHA-256 与被测试目录一致。机器可读证据见 `verification-0.6.2.json`。

开发检查输出保存在 `local_artifacts/usability-desktop`、`usability-time-recheck`、`usability-new` 与 `usability-narrow`。打包检查输出保存在 `test-results`；交付包及 SHA-256 清单保存在 `release`，均不进入 Git。

## 保留的边界

数据库、完整备份及导出结构版本仍为 1，未增加主进程接口或 renderer 权限。Run.snapshot、originalStartedAt、originalEndedAt、样品身份与数量规则由既有回归覆盖。筛选仅影响界面，不改变完整实验导出范围；运行中的记录缺少结束时间仍按既有规则列在待核对中。

本轮未进行真实私人仓库联网同步，既有离线模拟回归覆盖同步与报告队列；原生文件对话框在自动测试中提供隔离路径。程序没有代码签名。本轮是软件交互与数据完整性验证，不是实际仪器数据或科研结论验收。
