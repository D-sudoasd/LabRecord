# LabRecord 0.4.0 验收记录

工程检查使用合成实验与独立临时用户目录。结果用于验证记录、文件和软件行为；实际实验结论由仪器数据与实验条件判定。

## 数据与桌面流程

33 项数据检查覆盖：准备 6 / 计划 4 / 备样 2；启用备样、重测、跳过、中断；防止重复点击、全库单个进行中操作；跨午夜与时间原值/修正历史；中文、前导零、自定义字段、单位、空值及旧 v1 备份；数据库失败回滚与附件校验。

报告归档新增检查覆盖：完整报告和索引原子提交、保留其他备份文件、同一任务重试无重复版本、分段重组与损坏拒绝、两台设备同时归档后索引合并、公开库拒绝写入、离线任务重启恢复、更换仓库不转移旧任务、删除用户导出目录后待上传副本仍有效。慢速上传时继续保存备注与完成操作；上传中断后恢复为待上传。

0.4.0 打包程序执行 10 项桌面流程，全部通过：规划—现场—导出—备份恢复；粘贴旧格式；正常及异常退出恢复；保存失败保留输入并重试；页面快捷键、数量预览与搜索清除；用时跨午夜、超过 24 小时、修正与重启；键盘与缩放；备样/重测/跳过/中断/时间修正；快速录入与真实原生 PDF/HTML/JSON；归档状态、开关和离线失败后的现场操作。归档开关使用合成接口状态检查交互；真实云端读写见下面明确注明版本的联网验收。

## 界面与键盘操作

[ui-validation.json](ui-validation.json) 保存 0.4.0 Windows 打包运行环境、桌面检查时间、窗口与缩放组合、颜色对比值、软件包摘要以及云端检查复用依据。宿主显示缩放为 125%；窗口分别为 1366 × 768 / 100%、1100 × 800 / 125%、900 × 700 / 100% 和 150% 应用缩放。

检查页面横向溢出、顶栏实验选择/云同步/保存状态的边界以及滚动后完整可见的开始按钮。小窗口优先展示当前样品，时间线使用侧栏；[150% 缩放截图](images/live-small.png) 直接由 Windows 程序截图，避免浏览器截图在缩放时裁切。

大窗口的现场备注和问题/图片快捷入口处于首屏。Ctrl + 1 / 2 / 3 切换前保存输入；保存失败时保留页面及原输入；对话框内不切换页面。Alt + N 打开添加窗口，Esc 关闭并恢复入口焦点；清除搜索后保留搜索框焦点。数量预览检查准备 6 / 测试 4 / 备样 2，准备数量留空时保留未知值，测试 0 时可仅准备备样，不合理数量阻止提交。

本次用时由记录时间计算，检查 24:03:00、修正后的 00:03:00 与重启后未结束操作的继续计时；显示不写入或补造时间。完成按钮、进行中状态和保存状态文字的实际对比值分别为 5.46、5.93 和 4.90，均高于 4.5；这三处检查不代表完整的辅助技术认证。

## 交付文件

Release 中的 SHA256SUMS.txt 与 delivery-manifest.json 保存最终 ZIP 的大小、SHA-256、CRC、关键文件与打包运行环境。公开软件包只包含合成示例表格，原始个人样品表在本地历史备份中保留。README 图片来自生成的概念插图和实际打包程序的合成界面。

复现命令：

```powershell
npm ci
npm run verify
npm run dist
npm run test:packaged
node scripts/check-release.mjs
npm run format:check
npm audit --omit=dev
```

显式联网检查需要访问指定私人测试库：

```powershell
node scripts/test-live-cloud.mjs 你的账号/私人测试库
```

单张图片上限 10 MB；备份及展开内容上限 512 MiB；云端报告上限 2 GiB。报告用于阅读与分析，恢复数据库使用完整 .labrecord 备份。原始仪器数据仅保存路径引用。程序未进行代码签名。性能或极限容量未经本次真实实验测定。
