## 使用数据的边界

JSON 导出记录附件信息；带图片的完整恢复使用 `.labrecord` 备份。关联的仪器数据文件保存路径引用，不复制原始仪器数据。CSV 文件包含文本编号，但 Excel 直接打开 CSV 时可能自行转换编号；需要保留前导零时优先使用 XLSX，或在 Excel 导入 CSV 时指定文本列。更改字段单位不会自动转换已有数值。
