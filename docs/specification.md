# 首版实现范围

## 0.8 开始页与字段顺序

1. 已有实验时可以回到开始页。左侧「开始页」、顶部实验列表里的「开始页」，以及全库搜索中的「回到开始页」，都只取消当前选择，不删除实验、样品或记录。开始页列出已有实验，可直接打开、新建或载入演示。
2. 软件启动时，若已有实验，仍进入正在进行的操作，否则进入列表中的第一个实验。只有实验库为空，或用户明确回到开始页时，才显示开始页。之后的保存和刷新不会把人从开始页拽回某个实验。
3. 开始页在另有进行中的操作时仍显示进行中提示，返回只选中该操作，不另写时间。
4. 自定义字段可以上移或下移。选项用逗号分隔时，输入过程保留末尾逗号；保存时去掉空白选项。用过的文件夹写法始终可以再次选中，包括只有一条时。保存实验设置后，规划与快速添加按该顺序显示。不提高 schemaVersion。已开始的操作仍保留开始时的字段与单位。

## 2026-10-23 易用性调整（未发布）

1. 快速添加中，空白的材料与制备状态默认折叠；已有填写值时展开并标明“已填写”。折叠不删除输入，其他编辑入口保持展开。安排待测样品默认数量 1；已知剩余数量在 2–1000 之间时可一次填入全部，确认加入队列才写入。
2. 普通现场页按主操作、常用快记、现场备注、记录问题和图片、当前数据文件夹的顺序呈现，再显示最近记录与下一项等提示。队列中序号与菜单共用一列，优先级放在状态旁，给样品文字保留宽度；选中长记录时只滚动队列内部以显示编号。保持专注模式、F8、保存与复制行为。
3. 测量计划可一次清除搜索、状态、计划差异和实际差异筛选，同时清空已选项。待核对清单可直接打开已有记录的时间或文件弹窗，先保存未写完的输入；取消不写入，保存失败留在原处。
4. 全库搜索打开后直接聚焦输入，提供清空并恢复输入焦点的按钮；结果超过首批时说明数量，并可继续显示。实验库标明当前实验；没有计划操作的样品结果准确标为打开规划。搜索、清空、显示更多和打开结果均不开始操作。
5. 不增加配置项、主进程接口、依赖或数据版本。沿用现有样品身份、数量、导出范围、开始时快照与原始时间规则。通过独立临时资料库中的真实 Electron 操作及打包程序回归验收。

## 0.7 实验工作台

1. `Ctrl+K` 未输入时列出全部实验。准备数量、不同样品、计划操作、备样、完成、待测、进行中、跳过、中断和未处理问题沿用实验概览口径。准备数量全部未知时显示“未知”；已知与未知并存时显示已知小计和未知组数，不把空值当零。重测复用样品 ID，只增加计划操作。
2. 每项实验可打开规划，或前往完整排序中最靠前的待测操作；已有进行中的操作可返回现场。规划页显示同一下一项。这些入口只选中目标，不开始、不完成、不修改记录，也不推断时间。
3. 继续输入时，除样品编号、样品名、文件夹名和实验名外，还可搜索稳定样品 ID、开始快照中的样品 ID、测量技术、制度、批次、手动名称、材料短名、状态、制备字段，以及实际扫描编号、仪器文件名和文件引用。操作 ID 和记录 ID 按完整字符串定位到那一条操作。备注、自定义值、实验说明和事件正文仍不参与搜索。方向键在结果间移动。
4. 回看在样品编号下标出实际值与开始时快照的不同；文件引用不计入这种不同。报告的 HTML 与 agent 说明在确有不同时写出同一对照。后来修改计划不改变该对照的计划侧，也不改 originalStartedAt / originalEndedAt。
5. 已有实际记录的样品编号优先使用开始时快照。现场页直接显示与开始时计划不同的实际值。现场队列、当前样品和实验库标出已有记录里时间不完整或文件未关联的操作；专注当前样品时缺项仍留在标题下。时间不完整打开时间修正，文件未关联打开实际参数，未处理问题打开问题列表；三者只打开，不写入时间，也不把问题标成已处理。尚未开始的计划不标成缺项。回看历史同时列出挂在操作上、以及只挂在该次实际记录上的事件；实验级事件不写入某一条操作的历史。报告的待核对清单列出这些已有记录的缺项和挂到操作上的未处理问题，不把尚未开始的计划写成缺记录。Excel 与 CSV 的操作记录用同一口径增加“待核对”列，没有缺项时留空。回看页使用同一份清单，打开对应操作时只选中，不开始。规划页另行标出队列中第一条待核对记录，去核对只选中，不开始。已记录用时只累加起止都已写入、且结束不早于开始的间隔；缺任一侧或顺序颠倒的记录单独计数，不按当前时间补齐。不改 SQLite、备份或 schemaVersion。
6. 现场队列、测量计划和回看的搜索可按稳定样品 ID、开始快照中的样品 ID、操作 ID 和记录 ID 筛选。规划页样品组搜索可用这些 ID 找到所在样品组。完整 ID 可直接匹配；至少 8 位十六进制（可含连字符）才按 ID 片段匹配。更短的文字仍只匹配编号、名称和该输入框原有字段，避免单个字符命中全部 ID。这些筛选不改变下一件待测、导出范围、Run.snapshot 或原始时间。备注和事件正文只在原本会搜索它们的输入框里生效。
7. 回看表显示稳定样品 ID，并可复制样品 ID 和数据文件夹名。已有实际记录时，样品 ID 和文件夹名都取开始时的记录；还没开始时使用当前样品 ID 和当前计划名。复制不写入记录，也不改原始时间。
8. 现场和回看可复制已保存的实际文件名和扫描编号。复制读取最新已保存的值。文件引用含路径、控制字符或其他不能作为名称复制的字符时，不提供复制按钮。复制不写入记录，也不改原始时间。
9. 现场在当前操作不是下一件待测时，显示完整排序里下一件待测的样品编号、方式、制度、批次、材料、状态、厚度、实验制度和数据文件夹。规划页的下一项使用同一内容。不显示备注。查看只选中该操作，不开始、不完成，也不推断时间。现场和规划页都可以复制下一件的数据文件夹名。现场复制不切换样品；规划页复制后仍留在规划页。两者都不开始，也不改原始时间。离开最近一条已结束的记录后，现场显示它的样品编号、用时、扫描编号和开始时的文件夹名；中断与完成分开标出。查看只选中，不开始。现场进度显示已知备样，并按当前样品所在样品组显示本组备样。本组数量取当前样品组，不取开始时快照。准备数量全部未填写时显示“备样数量未定”；部分未知时显示已知备样和未知组数。本组未填写时显示“本组备样数量未定”。重测不减少备样。启用备样时当前样品组排在最前并标明“当前样品组”；打开选择不创建样品。队列可直接启用本组备样，默认数量 1，不超过剩余备样；取消不创建样品。本组备样为 0 时不可用，数量未填写时仍可打开。默认前缀仍是 S。同一组已有编号共用一个前缀时，可点沿用该前缀，点击后才改预览编号。队列筛选不改变这一件。待测队列每一行显示数据文件夹：已有实际记录时用开始时写入的文件夹名，尚未开始时用当前计划名。已填写的扫描编号显示在同一行。队列搜索包含扫描编号、实际文件名和文件引用，不包含备注和事件正文。规划页样品组搜索和测量计划搜索使用同一操作文本；样品组备注仍可搜索。筛选不改变下一件待测。
10. 重测沿用原操作的样品 ID。队列、测量计划、现场和回看标出原操作的样品编号、扫描编号和开始时的文件夹名。回看搜索可以按这句来源找到重测行。查看原操作只选中，不开始，也不改原记录的快照和原始时间。没有原操作时不编造来源。HTML、Markdown、Excel 和 CSV 写出同一句来源，并保留原操作 ID；不是重测时来源留空。重新导入不把“重测来源”写成样品字段。
11. 现场时间卡、回看起止时间、时间修正中的原始时间、实验概览里的进行中操作，以及规划或回看页顶部的进行中提示，都按该次记录保存的时区偏移显示。挂在该次实际记录或对应操作上的事件，时间线、回看历史、问题列表和概览也使用这一偏移。没有挂到实际记录的事件仍按当前电脑显示，不为它编造偏移。换一台处于其他时区的电脑打开时，已关联事件的钟点不变。没有时区名时显示 UTC 偏移。HTML 与 Markdown 报告在 UTC 之外写出同一记录时区钟点，缺时间时写“未记录”，不补当前时间。报告里挂到实际记录的事件同时写出这个钟点和 UTC；没有实际记录可对照的事件只保留 UTC。Excel 与 CSV 的事件表增加“记录时区时间”，没有可对照的实际记录时留空；重新导入不把这一列写成样品字段。这只改变显示，不改 startedAt、endedAt、originalStartedAt 或 originalEndedAt。在现场查看其他样品时，页内进行中提示同样显示该次记录的时区钟点和开始时的数据文件夹名，并可复制该文件夹名。复制先保存未写完的输入，再读取最新快照里的开始时文件名；不切换样品，不开始或结束操作。
12. 现场可用 Alt + ← / → 按完整排序选中相邻操作。搜索、状态筛选和专注模式不改变这一顺序，被筛掉的操作仍可被选中。停在输入框、对话框、菜单、正在保存，或已经到队列两端时无效。只选中，不开始、不完成、不跳过、不调整顺序，也不写入时间。
13. 规划页展开样品后，列出该样品的每次操作及状态。点某一条只选中该操作并进入现场，不开始、不完成，也不改原始时间或快照。未指定操作时，优先打开进行中的操作，否则打开完整排序里最早的待测；没有待测时打开最后一条。已完成或已中断的原操作不会挡住同一样品上后来的重测。组内中断和跳过在完成数旁边单独标出，不计入已完成。
14. 回看可按待测、进行中、已完成、已跳过、已中断筛选操作记录，并与搜索和待核对条件叠加。清除筛选后恢复全部计划。筛选不改变导出范围、Run.snapshot 或原始时间。打开筛出的操作只选中，不开始、不完成。
15. 测量计划可按待测、进行中、已完成、已跳过、已中断筛选，并与原有搜索叠加。切换状态或搜索会清空已选测量，避免把看不见的已开始记录留在批量配置里。“选择当前全部”只选中当前筛出的行。已有实际记录的操作仍不能批量改制度。筛选不调整顺序，不改 Run.snapshot 或原始时间。
16. 规划表在未展开样品组时，于计划数和备样旁单独标出该组进行中、已完成、已中断、已跳过和待测的操作数。某一项为零时不显示。没有安排操作的组不显示这行，也不把空操作数写成零。这些数字不改变准备数量、计划样品数或备样。只供查看，不开始操作。
17. 现场队列每一行显示已填写的厚度、宽度和高度。已有实际记录时用开始时快照里的尺寸，尚未开始时用当前计划。没填的一边不显示，也不编造单位。备注不显示在这一行。后来修改计划不改变已开始那一行的尺寸，也不改 originalStartedAt 或 Run.snapshot。专注当前样品、队列收起时，当前标题使用同一句尺寸；窄窗口单行放不下时仍可从标题提示读到全文。实际厚度、宽度或高度与开始时不同时，队列和专注标题写成“实际 … · 计划 …”；没有差异时仍只显示一句。队列、测量计划、样品组搜索、回看搜索和全库搜索都可以按这句尺寸查找。已开始的操作用开始时尺寸和实际尺寸，不用后来改过的计划尺寸。备注和自定义值仍不因此变成可搜内容。这不改 Run.snapshot 或原始时间。
18. 现场队列和专注标题显示已填写的成分、加工工艺、热处理制度和其他工艺。已有实际记录时用开始时快照，尚未开始时用当前计划。没填的不显示。备注、制备备注和自定义值不显示在这一行。后来修改计划不改变已开始那一行，也不改 originalStartedAt 或 Run.snapshot。
19. 现场队列在已有实际记录的行显示用时。起止都已写入且结束不早于开始时，用与回看相同的口径；缺任一侧或顺序颠倒时显示“未计入”，不按当前时间估算。尚未开始的行不显示用时。这只改变显示，不改 startedAt、endedAt 或原始时间。
20. 规划表未展开时，在操作状态旁显示该组已记录用时。只累加起止都已写入且结束不早于开始的记录；缺任一侧的次数单独标出，不按当前时间估算。没有实际记录的组不显示这行，也不写成零。展开后的每次操作在已有记录时用同一口径显示用时。Excel 与 CSV 的样品组表增加“已记录用时”和“未计入次数”，没有完整起止或没有缺记时留空，不写成零。重新导入不把这两列写成样品字段，也不生成实际记录或补齐未知时间。HTML 样品组表和 Markdown 的“样品组已记录用时”使用同一汇总；没有实际记录时 HTML 写“未记录”，Markdown 写“尚无实际记录”，不写成零，也不按当前时间估算。这不改变准备数量、计划样品数、备样或原始时间。
21. 尚未开始的队列行、专注标题，以及队列、测量计划、样品组、回看和全库搜索，使用这一件样品的当前计划：样品组加上该样品自己的覆盖参数。已有实际记录时仍只用开始时快照。后来修改样品参数不改变已开始的行、Run.snapshot 或原始时间。备注和自定义值仍不因此显示或变成可搜内容。
22. 规划页展开样品后，只标出这一件自己填写、且与样品组不同的厚度、宽度、高度和制备字段，并标明“本样品”。留空而沿用样品组的字段不重复标出。备注和自定义值不写在这里。这只说明当前计划，不改样品组、备样、已开始记录的快照或原始时间。
23. 测量计划用同一句“本样品”标出该样品当前与样品组不同的尺寸和制备。已有实际记录后，这里仍显示当前计划的差异，不改写开始时快照或原始时间。备注和自定义值不写在这里。筛选和批量配置制度的范围不变。
24. 样品组未展开时，若有样品的当前参数与组不同，标出件数，不列出明细，也不把沿用组值的样品算进去。没有这种样品时不显示，不写成零。展开后的“本样品”仍是明细。Excel、CSV、HTML 和 Markdown 写出这些样品的编号和差异；没有差异时留空，不写成零。重新导入不把“样品差异”写成样品字段，也不改已有记录。界面上未展开的件数不因此列出明细。这不改样品组、备样、已开始记录的快照或原始时间。
25. 已有实际记录后，若这一件样品的当前计划在尺寸、制备或实验制度上与开始时快照不同，现场队列和专注标题写明“当前计划已不同”，并给出当前计划的尺寸、制备或实验制度。开始时的尺寸仍照常显示。只改备注不会出现这句。尚未开始的行不写这句。这只改变显示，不改 Run.snapshot 或原始时间。回看、HTML、Markdown，以及 Excel 与 CSV 的操作记录用同一句；没有差异时留空。重新导入不把“当前计划差异”写成样品字段，也不改已有记录。尚未开始的操作不写这句。
26. 样品组未展开时，若该组已有实际记录的当前计划与开始时快照不同，标出件数，不列出尺寸、制备或实验制度明细。没有这种记录时不显示，不写成零。只改备注不计数。这不改 Run.snapshot 或原始时间。
27. 队列、测量计划、样品组、回看和全库搜索可以按“当前计划已不同”这句里的当前尺寸、制备或实验制度查找已开始的操作。开始时的尺寸仍可按原句查找。只改备注不会因此被搜到。尚未开始的操作不会因为这句被搜到。搜索不改 Run.snapshot 或原始时间。
28. 现场队列在已有记录的当前计划与开始时快照不同时，提供“计划已变”筛选。它只隐藏其他行，不改变完整排序里的下一件待测，不开始或结束操作，也不改 Run.snapshot 或原始时间。没有这种记录时不显示该筛选。规划页未展开的件数可以打开其中排序最前的那一件，只选中，不开始，也不改其他记录的状态。
29. 现场正在查看的操作不是完整排序里第一条待核对记录时，显示该记录的样品编号和缺项。查看先保存未写完的输入，再只选中那一条，不开始、不完成，也不补时间或文件。已经停在这一条上时不重复显示。尚未开始的计划不因此出现。这不改 Run.snapshot 或原始时间。
30. 当前样品标题上的缺项分别打开对应位置：时间不完整打开时间修正，文件未关联打开实际参数，未处理问题打开问题列表。队列同一行也标出未处理问题，点这一行仍只选中。只打开，不写入时间或文件，不把问题标成已处理，也不开始或完成操作。尚未开始的计划没有这些按钮。已处理的问题不再标出。

## 0.6.1 金属材料使用习惯优化

1. 新实验默认名称为 `{experiment}_{sample}`，普通测量不追加操作流水号。快速添加、安排测试、启用备样和临时样品统一默认 S 前缀，跨样品组连续分配。物理样品编号按安排时的顺序固定，实际开始顺序由 Run.number 记录，重排不重编号。
2. 同一样品的不同测量保持稳定 sampleId。文件夹名默认是实验编号加样品编号；同一件样品的第 2 次及以后测量加 `_02`、`_03`，只统计这件样品，不跟其他样品连号。资料库里未经设置保存的旧默认规则 `{experiment}_{sample}_{run:03}` 在打开时改为上述规则，只重算尚未开始的自动名称。已经开始的文件名、Run.snapshot 和原始时间保持不变。在设置里明确保存过的 `{run}` 规则继续沿用，界面说明该数字是全表计划序号，不是样品编号。
3. 样品准备独立记录 composition、processing、heatTreatment、otherTreatment，分别对应成分、加工工艺、热处理制度、其他工艺。字段可选；空字符串或缺字段表示未填写，“无”表示明确没有。支持文字、单位和工序顺序，不从 NOHR_aged 等原始标记推断或拆分。成分的 wt.% / at.% 由用户明确填写，不换算。
4. 快速添加、编辑、批量设置、具体样品覆盖、规划状态展示与搜索支持上述字段；沿用参数和连续录入保留制备信息。测量的实验制度独立保存，避免和制备热处理混淆。
5. 新字段经主进程与备份校验，保存在既有实体 JSON 的可选扩展中，SQLite 表、user_version、备份版本和 schemaVersion 保持 1，不回填旧 Run.snapshot。导入、XLSX/CSV/JSON 和 HTML/PDF 保留原始状态、单位、空值与开始时制备状态。旧自定义“成分”等字段与新增字段分别保留，不能串列或覆盖。
6. 在独立临时目录完成编号、重测、旧模板切换、历史冻结、旧备份、同名自定义列往返以及真实桌面、窄窗口和打包程序验证。本轮仅本地交付，不自动推送或公开发布。

## 删除与右键菜单

样品组、样品、测量和没有实际记录的实验可以删除。右键菜单放已有的编辑、复制、安排、查看和排序，不在菜单里开始、完成或中断。

1. `deleteGroups` 删除同一实验里没有 Run 的样品组，并去掉这些组的样品、未开始测量，以及指向这些测量的事件。准备数量随组消失。组里已有 Run 时整次拒绝。
2. `deleteSamples` 移出没有 Run 的样品及其测量和对应事件。样品组与 preparedCount 保留，计划数减少，备样数增加。
3. `deleteItems` 只删除 pending 或 skipped、且没有 Run 的测量。不改其余测量的 plannedName、nameNumber 和顺序。若该样品再无测量、也无 Run，则去掉样品，使其回到备样。进行中、已完成、已中断一律拒绝。
4. `deleteExperiment` 只删除没有任何 Run 的实验及其样品组和未开始测量。已有 Run 的实验保留全部记录、快照和原始时间。
5. 删除在确认后一次提交。失败整次回滚。不提高 schemaVersion 或 user_version。

## 文件夹名

界面只呈现一种数据文件夹名：实验编号加样品编号。同一件样品的后续测量加 `_02`。材料、状态和制度写在样品与测量记录中。设置里的「其他写法」继续保存原有 `namingPattern`；已经开始的文件名、快照和原始时间不变。不提高 schemaVersion 或 user_version。

## 原位实验制度

样品组增加实验制度。界面把 In situ / Ex situ 显示为原位 / 非原位，保存的值不变。选原位后可写升温、保温、气氛、载荷或采集间隔；空着也能开始。具体样品留空则沿用样品组，写了字只属于这一件。改成非原位或未定不删除已写文字。

不提高 schemaVersion。旧样品组没有该字段时读作空字符串。已有 run.snapshot 不回填。新的开始把当时的有效制度写入快照，并把同一文字作为实际实验制度的初值。开始后再改计划，不改变该次快照和原始起止时间；现场若不同，只改实际实验制度。

导入认“实验制度”“实验程序”“原位制度”。没有这些列的旧表不推断制度。报告里的样品组表是当前制度；每次操作另记开始时实验制度和实际实验制度。

同一状态仍是一个样品组，不按工艺拆组。样品统称是这一组的公共名字。安排测试时每一件单独填写样品名和实验制度：编号仍按前缀加序号生成，并避开已有编号；样品名默认是统称或状态加同一序号，清空则不保存单独名字；制度留空或与样品组相同则沿用样品组。`arrange` 可以带与件数等长的 `specimens`，不带时和原来一样不写覆盖参数。开始后的快照保留当时的名字和制度。不提高 schemaVersion。
