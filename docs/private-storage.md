# 私人实验数据与报告

源码与下载包公开发布；实验记录保存于本机用户数据目录，可连接自己的 GitHub 私人库。每次同步与报告归档均检查仓库可见性。电脑之间分别登录，凭据不进入备份、报告或 Git。

在 GitHub 创建私人库并初始化 README，或由已登录 GitHub CLI 的软件创建私人库。已有私人库可使用仅选择该库、Contents 读写权限的细粒度令牌。另一电脑独立登录、连接同一库、同步接收实验与图片。原始仪器数据是路径引用，需要另行迁移。

“生成报告后保存到私人库”默认开启，可在云同步页关闭。导出先在选择的本机目录生成完整报告，再复制到本机受管理的待上传目录。成功登记后开始后台传输；移动已导出的本机目录不影响已登记任务。

本机保存与云端上传分别显示。失败可重试；重新启动、连接或同步时会尝试当前私人库的任务。任务绑定原仓库与目录，更换仓库后需重新连接原库才能上传原任务。关闭自动归档会保留待上传任务。成功后清理待上传副本，用户导出的报告继续保留。

私人库 labrecord/reports/README.md 和 index.json 提供阅读入口。每次导出使用稳定实验 ID 与独立报告 ID 保存新版本；报告正文与索引一起提交。并发分支变化时重新读取索引后重试，重试同一任务不会新增重复版本。

点击“刷新云端报告”列出版本，“下载完整报告”选择本机目录。下载校验文件、分段和 SHA-256，全部通过后才公布最终目录。PDF/Markdown 用于阅读；HTML 下载后离线打开。大于 20 MiB 的文件分段存放，通过软件下载重组。

将整个报告目录交给后续 agent，先读 README-agent.md，再读 records.json，并按 manifest.json 核对图片。空值表示未记录；计划参数不是独立测量值；原始点击时间与修正历史分别保留。恢复软件中的实验数据库使用完整 .labrecord 备份。

单份云端报告最多 2 GiB，完整备份及展开内容最多 512 MiB，图片单张最多 10 MB。软件不会自动删除云端历史版本。
