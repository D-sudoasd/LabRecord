# 同步辐射现场使用：样品、测量制度与命名

LabRecord 0.6 将物理样品和测量操作分开。一件试样可以先做旋转扫描，再做分级加载，结束后追加重测；这些操作使用同一个样品 ID，各自保存方式、制度、批次、名称和实际记录。

## 建议的现场流程

1. 新建本次机时的实验，填写唯一实验编号。需要沿用上次机时的命名规则、自定义参数和单位时，选择“复用已有实验设置”。
2. “新增样品”填写统称、成分、加工工艺、热处理制度和其他工艺，按需保留原始状态标记。成分写明 wt.% 或 at.%；制备工序可按先后写变形量、温度、时间和冷却方式。热处理和其他工艺可选“无”，留空表示未填写。准备数量和计划测试数量分别填写，厚度、宽度及单位独立保存。
3. 在“测量技术与制度”填写测量技术。详细载荷、温度、气氛、曝光、旋转范围等写在实验制度里，按真实条件填写单位，不自动换算。
4. 在“测量计划”选择一项或多项：配置制度，或者“同样品追加制度”。追加可一次安排多次测量，不创建新物理样品、不占用备样。文件夹名在保存计划时确定，可直接复制。复制前会先保存正在修改的内容；保存失败时不会复制旧名称。
5. 现场核对本次制度和名称，再开始操作。开始后名称和计划快照固定。现场实际条件变化仍写入实际参数、备注或问题；结束后仅选中下一项，由用户决定何时开始。
6. 设备或装样异常可先记录问题，再中断。需要重复该次测量时用“安排重测”；它复用源操作开始时的制度，并保留 `repeatOf`。需要另一种制度时用“同样品追加制度”。
7. 回看页可以按编号、制度、批次、名称或备注查找，导出的 HTML/PDF、CSV/XLSX 和完整 JSON 都保留测量信息。完整备份包含新的计划元数据，恢复前仍校验并备份本机数据。

## 命名示例与规则

以下均为合成示例，不代表实际实验。

```text
P212-202610_S01
P212-202610_S02
P212-202610_S03
```

普通测量每件样品的文件夹名是实验编号加样品编号，不再附加全表流水号 001、002。样品编号跨组连续，启用备样时接着分配。编号按安排顺序固定，实际开始顺序另行记录；调换队列不会改已贴样品号或已复制的名称。

同一件样品预排多次测量时使用 `P212-202610_S01`、`P212-202610_S01_02`、`P212-202610_S01_03`。`_02` 表示这件样品的第 2 次计划测量，不跟其他样品连号，也不代表实际开机次序。准备 3 个、安排 1 件物理样品、计划 3 次测量时，仍保留 2 个备样。材料、状态和制度写在记录里，不写进这个文件夹名。

下面的占位符只在实验设置中打开「其他写法」后使用。

| 占位符         | 来源                                                                        |
| -------------- | --------------------------------------------------------------------------- |
| `{experiment}` | 实验编号                                                                    |
| `{material}`   | 材料短名；未填写时沿用样品统称                                              |
| `{state}`      | 原始样品状态；“未指定”省略                                                  |
| `{sample}`     | 物理样品编号                                                                |
| `{mode}`       | `IS` 原位、`ES` 离位，未定省略                                              |
| `{technique}`  | 用户填写的技术，如 SXRD、SAXS                                               |
| `{regime}`     | 制度短码，如 monotonic、cyclic、step、rotation、thermal、static，也可自定义 |
| `{batch}`      | 批次或条件短码，如 B01、RT、350C-Ar                                         |
| `{run:03}`     | 全表计划序号，三位补零；也支持 `{run}` 与 1–9 位补零。这不是样品编号        |

新实验的文件夹名是 `{experiment}_{sample}`。界面只显示这一个结果。材料和制度记在样品与测量里，不另编名字。设置里的「其他写法」仍可沿用以前的规则，也可自己写。资料库中未经设置保存的旧默认 `{experiment}_{sample}_{run:03}`，打开后改为实验编号加样品编号，只更新尚未开始的名称；已经开始的文件名保留。空字段会省去，原始状态、参数和单位始终保存原文。

自动名称会避开本机库中已预留和已有实际记录的名称。同一基本名再次使用时加 `_02`、`_03`。某一项可以单独改文件夹名；非法 Windows 名称或手工重名会在保存前提示。样品编号按安排顺序固定，调整队列和提前测某项不会改已有文件夹名。

保存写法只更新尚未开始、且没有单独改过的文件夹名；已经开始的记录保持原名。追加测量或重测不会沿用单独改过的文件夹名。历史测量配置可以跨实验复用，制度详情仍可修改。

## 保存失败后继续操作

新建实验、快速添加样品、安排测试及配置/追加制度都保留同一保存请求。明确未写入的输入错误会保留草稿并允许直接修正；如果结果暂不确定，内容固定，可以重试同一请求。返回列表或关闭弹窗前先重新读取本机记录，避免把已经保存的操作再添加一遍；读取失败时保留窗口和重试内容。连续添加成功后自动回到样品统称输入框。

## 使用范围与兼容

命名和测量规划完全离线，只使用用户录入的记录，不检查目录是否存在，也不读取、解析或匹配 SXRD 数据文件，不连接外部处理软件。文件引用仍是原有的手工记录能力。

一次最多追加 1000 项，每项追加次数为 1–100；追加后实验最多 10,000 项。物理样品、备样和操作数分别统计。批量配置统一所选项的测量参数，保留各项临时名称；更换搜索条件会清空选择，避免误操作隐藏项。已有实际记录不能改为另一制度，应追加新计划。

SQLite 表结构、`user_version`、备份版本和 `schemaVersion` 保持 1。材料短名、计划测量配置、预留名称、命名序号和开始时测量快照都是可选扩展；旧记录读取时不回填测量元数据，不改写已有快照或原始起止时间。新记录应继续使用 0.6 或更新版本，旧版本不了解操作级测量配置。

本次验证使用临时目录与合成实验。工程检查确认应用行为，不代替束线条件、仪器数据或科研结论的验收。
