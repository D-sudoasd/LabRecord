LabRecord · 使用说明

提前规划，现场随手记录。

中文界面，离线记录。快速填写名称与尺寸，现场记录起止时间和变化，结束后一键生成报告，也可通过私人仓库换电脑接续。

1. 开始使用

  1. 将 Windows ZIP 完整解压，双击其中的 LabRecord.exe。运行时不需要网络、Excel、Node 或 Python。项目源码目录内也可以双击“启动LabRecord.cmd”。
  2. 点击“新建第一个实验”，填写名称和唯一的实验编号；以后用顶栏切换实验。
  3. 也可以先点击“载入演示实验”。Ti-A-热处理组准备 6 个，安排 4 个，保留 2 个备样。演示数值不代表真实实验。

界面左侧依次是实验规划、现场记录和回看导出。底部书本按钮打开本说明，齿轮进入实验设置、保存与备份、云同步。顶栏可直接打开实验概览和云同步，并一直显示本机保存状态。

2. 实验前安排样品

一个样品组表示成分、加工工艺、热处理制度和其他工艺相同的试样。样品统称填写材料牌号或组名，制备信息分别填写，可写明工序顺序、变形量、温度、时间和冷却方式。成分请注明 wt.% 或 at.%，不会自动换算。热处理和其他工艺可点击选“无”；留空表示未填写。原始状态标记仍原样保留，不自动拆解。同组每件样品可以再单独修改参数。

  1. 在“实验规划”点击“新增样品”，或按 Alt + N。只填样品统称即可创建一项待测样品；准备数量和计划测试数量默认均为 1，可一起调整。状态、厚度和宽度按需要填写，单位默认 mm，也可更改或留空。
  2. 连续录入时用“保存并继续添加”，或 Ctrl + Enter；尺寸、数量和实验条件继续保留，只需填写下一组名称与状态。需要复制已有参数时点击“沿用上一组参数”。仅准备备样时将计划测试数量填 0；准备总数未知可留空。
  3. 准备数量下面可以选择实验方式。选“原位”或“非原位”后直接填写这一组常用的实验制度，例如升温、保温、气氛或载荷；不填也可以先安排。点击保存即生成样品编号和数据文件夹名，并进入队列。已有样品组用“安排测试”增加待测样品：每一件都有编号、样品名和实验制度。样品名默认是统称加序号，可以改，也可以一次粘贴多行；清空后现场显示编号。制度留空则沿用样品组，写成不同的文字才只属于这一件。改成“非原位”或“未定”不会删掉已写的制度。高度、制备/试剂、优先级、编号前缀、备注和自定义参数仍在“更多信息”里。未展开时，计划数和备样旁边会标出这一组进行中、已完成、已中断、已跳过和待测的操作数；没有的状态不显示。有实际记录时，旁边另写已记录用时；起止不完整的次数单独标出，不按当前时间估算。还没安排操作或还没有记录的组不显示这些行。展开后，如果某一件的厚度、宽度、高度或制备和样品组不同，会标成“本样品”；没单独填的仍沿用样品组，不重复显示。测量计划的每一行也这样标。样品组不展开时，只写有几件和本组不同，不列出具体差异；没有这种样品时不显示。导出的表格和报告会写出样品编号和具体差异；再导入时这一列不会变成样品字段，也不会改已有记录。已经开始之后如果又改了这件样品的厚度、制备或实验制度，现场队列和专注标题会写“当前计划已不同”，开始时的记录仍保留。只改备注不会出现这句。回看和导出的报告、操作表也写这句；再导入时不会变成样品字段。样品组不展开时，只写有几件已经开始的记录后来计划变了，不列出具体尺寸。只改备注不计数。队列、回看和全库搜索可以按改后的尺寸、制备或实验制度找到这件；只改备注仍搜不到。队列里出现“计划已变”时，可以只看这些已开始的记录；下一件待测仍按完整排序，不会因此被开始。规划页上的件数可以点开其中最早的一件，只查看，不开始。备注和自定义值不写在这里。已有记录的每次操作也显示同一口径的用时。导出的 Excel 和 CSV 样品组表也有“已记录用时”和“未计入次数”；没有可计入的记录时留空。把表再导入时，这两列不会变成样品字段，也不会生成实际记录。HTML 和 Markdown 报告的样品组也写出同一用时；还没有实际记录时不会写成零。展开行首箭头后，名字和制度可以直接改。同一件样品的每次操作会标出序号和状态。点某一条只打开那一次，不开始。已跳过的操作旁边可以恢复到待测，仍留在规划页，不生成实际记录；写过的原因会显示在这一条上，恢复后不再显示。已中断的操作不能从这里恢复。点“现场记录”时，优先打开进行中的操作，否则打开最早的待测；已完成或已中断的原操作不会挡住后来的重测。组内若有中断或跳过，会在完成数旁边单独标出。
  4. 规划表直接编辑名称、准备数量、厚度、宽度和备注，修改自动保存。编辑按钮可调整状态与完整参数；复制按钮复制样品组。选择多组后，“批量设置参数”只修改勾选的字段。
  5. 在样品组、组内样品、测量计划、现场队列和回看记录上单击右键，可以编辑、复制、安排、查看或删除。文字框里右键仍可剪切、复制和粘贴。删除前会再确认一次。已经开始或完成的测量，以及带有这些记录的样品组和实验，都不能删除。移出还没开始的样品后，准备数量不变，这件回到备样。删掉整组时，这一组的准备数量一并去掉。
  6. 在齿轮“实验设置”中添加文本、数值、选项字段及单位，例如成分、温度、浓度或载荷。数值字段不能保存非数值，选项字段从设定列表选择。厚度和宽高单位分别填写，不会自动换算数值；高度不要求填写。
准备 6 个，安排 4 个，就显示 2 个备样。
准备数量包含备样。计划测试样品数按不同物理样品统计；计划操作数另行统计，重测增加操作而不增加物理样品。降低准备数量后若少于已安排数量，表中显示“准备不足”，请核对实际情况。

实验概览

在任意页面点击顶栏“实验概览”，查看当前实验的准备数量、不同计划样品数、计划操作数与未启用备样。准备数量未填写时显示“未知”；已知与未知样品组混合时，显示已知小计及未知的组数，不将空值当作零。完成、待测、进行中、跳过和中断分别统计；重测复用样品 ID，只增加计划操作。

概览另列出全库进行中的操作。如果在查看另一实验，点击“切换并返回”即可先保存当前输入，再返回正在操作的准确样品与操作。保存失败时保留原页面和输入，不自动开始其他操作。概览里也可以复制进行中记录开始时的数据文件夹名，复制后仍留在概览，不切换实验。实际记录与开始时计划不同时，概览会列出这些操作；打开时只选中那一条并进入现场，不开始。只改备注、文件引用或当前计划不会出现。没有这种记录时不显示。专注模式也保留顶栏概览入口。

实验库与下一项

按 Ctrl + K，或点击左侧“全库搜索”。还没输入时，这里列出全部实验：准备数量、不同计划样品、计划操作、备样，以及完成、待测、进行中、跳过和中断。准备数量全部未知时显示“未知”；只有一部分未知时，显示已知小计和未知的组数。重测增加计划操作，不另计样品。有已经计入的用时时，实验卡片会写出已记录用时；起止不完整的次数单独标出。没有可计入的记录时不显示用时，也不写成零。

和 CSV 写出同一句；“最近结束”列再导入时不写入样品，也不改已有记录。规划页、现场、实验库和实验概览的最近记录还会写出这次结束的钟点，用的是记录当时的时区，不是现在这台电脑的时区。没有写下结束时间时不写。队列搜索找不到这句钟点。现场队列、规划页展开后的操作和测量计划里，每一条已经结束的操作也写出这个钟点。正在进行和还没开始的不写。队列和测量计划搜索找不到这句。正在查看已经结束的操作时，标题上也写出这个钟点；收起队列后仍然看得到。正在进行和还没开始的标题不写。正在看别的样品时，现场和实验概览也可以复制最近一条记录开始时的数据文件夹名。复制后不切换样品，概览不关闭。没有可复制的名称时不提供。现场队列、规划页展开后的操作和测量计划还会写出开始钟点。还没开始的不写。正在进行的只写开始，不写结束。队列和测量计划搜索找不到这句。现场标题把开始钟点写在状态后面，不另起一行。正在进行时也能看到，收起队列后仍然看得到。还没开始的标题不写。回看在钟点下面写出记录时区。Excel 和 CSV 的“开始钟点”“结束钟点”写同一句，没有对应时间时留空。再导入时不写入样品，也不改已有记录。现场队列、测量计划和规划页展开后的操作，会写出已经填写的实际文件名。只写了文件引用或备注时不写。还没开始的不写。现场标题把同一句写在状态后面，不另起一行。收起队列后仍然看得到。规划页、现场、实验库和实验概览的最近记录，以及报告里的最近结束，也会写出这个实际文件名。只写了文件引用或备注时不写。规划页、现场和实验概览还可以复制这个实际文件名。复制后不切换样品，规划页仍留在规划页，概览不关闭。名称里含有路径或控制字符时不提供复制。文件引用不复制。正在看别的样品时，现场会标出进行中操作已经填写的实际文件名，也可以复制。实验概览里的进行中操作同样写出并可以复制。复制后不切换样品，概览不关闭。只写了文件引用或备注时不写、不复制。离开现场后，规划页和回看页顶栏的进行中提示也会写出这个实际文件名，并可以复制。复制后仍留在当前页，不返回现场。正在看别的样品时，现场、实验概览，以及规划页和回看页顶栏，也会写出进行中操作的扫描编号，并可以复制。复制后不切换样品，离开现场后仍留在当前页，概览不关闭。只写了备注或文件引用时不写、不复制。编号里含有路径或控制字符时不提供复制。HTML ID、文件夹名、实验名、测量制度、批次、材料短名、制备字段、扫描编号和文件引用查找。操作 ID 和记录 ID 需完整输入，并打开对应的那一条操作。有缺项的样品结果会带上时间不完整、文件未关联或未处理问题；没有缺项时仍只显示实验名和编号。顶栏实验列表和实验库在确有实际记录与开始时计划不同时标出条数；没有这种记录时不显示，也不写成零。只改备注、文件引用或当前计划不计入。备注、自定义值和实验说明不参与搜索。

“未处理问题”在操作完成后仍保留。展开“查看详情”可核对问题、样品、操作与实际记录；关联样品的问题可点击“查看现场”，没有样品关联的实验级问题不会跳到其他样品。“标记已处理”只登记处理状态。概览内容可独立滚动，关闭后返回原页面和滚动位置。

同一样品安排多种制度

在规划页“测量计划”中，可按待测、进行中、已完成、已跳过或已中断筛选，再选择一项或多项操作，然后“配置制度”或“同样品追加制度”。切换筛选会清空已选内容；“选择当前全部”只包含当前显示的行。已经开始的记录仍不能批量改制度。已经开始的每一行另显示用时；起止不完整时写“未计入”，不会用当前时间估算。还没开始的行不显示用时。每一行显示已填写的厚度、宽度和高度：已经开始的用开始时的尺寸，若现场改过则同时写出实际尺寸和计划尺寸；还没开始的用当前计划。后来改计划不会改掉已经开始那一行。如果开始之后又改了尺寸、制备或实验制度，这一行会另写“当前计划已不同”；只改备注不会出现这句。这时可以只看“计划已变”的测量，并能和状态、搜索一起用；它只隐藏其他行，不改变顺序，也不会开始操作。没有这种记录时不显示这个筛选。如果现场记下的厚度、尺寸、制度或其他实际字段与开始时不同，可以只看“实际已改”；只改备注、文件引用或当前计划不会出现。没有这种记录时不显示。它只隐藏其他行，并清空已选测量。如果现场改过实验制度，这一行会另写“实际制度”，并带上开始时的制度。只改当前计划不会写成实际制度。这句实际制度可以在测量计划、现场队列、样品组、回看和全库搜索里找到。现场改过的实际样品名、实验方式或制备试剂也可以在这些地方按改后的文字和开始时的文字找到。只改当前计划、备注、文件引用或自定义值不会因此被搜到。还没开始的操作不会因为这句被搜到。现场队列、当前标题、测量计划和回看也会写出同一句。HTML 和 Markdown 在确有不同时写出同一句。现场队列、当前标题和回看也会写出同一句。HTML 和 Markdown 报告在确有不同时写出同一句；没有改过实际制度时不写。备注和自定义值仍然不参与这些搜索，也不写在这句里。已跳过的测量可以在这里恢复到待测，仍留在测量计划，不生成实际记录；写过的原因会显示出来，恢复后不再显示，也不能靠搜索找到这句原因。已中断的测量不能从这里恢复。筛选不调整顺序。回看里已完成或已中断的操作也可以安排重测，仍留在回看，不另增样品或备样；已经有一条还没做完的重测时，不会再加一条。进行中、待测和已跳过没有这个入口。每项各自保存实验方式、测量技术和制度。单调拉伸、循环、分级、旋转扫描、升降温和离位静态测量均可使用。

追加制度沿用同一个物理样品 ID，不占用备样；每项可以一次追加多次测量。现场“安排重测”用于重复已完成或中断的那次制度，并保留原操作关联。规划页展开后也可以安排重测，仍留在规划页，不另增样品或备样；已经有一条还没做完的重测时，不会再加一条。如果下一项正好是重测，规划页、现场和实验库会标出原操作的样品编号、扫描编号和开始时的文件夹名；不是重测时不写这句。需要另一种制度则选择“同样品追加制度”。历史测量配置可跨实验复用，离位同样能填写条件详情，切换方式不会删去制度文字。

数据文件夹

文件夹名就是实验编号加样品编号，例如 P212-202610_S01。同一件样品再测一次，写成 P212-202610_S01_02，样品编号本身不变。这是合成示例，不代表真实实验。

材料、状态和实验制度写在样品与测量记录里。测量计划里复制文件夹名即可。已经开始的记录保持原名。设置中的「其他写法」可以沿用以前保存的规则；没有特意保存过的旧流水号，打开后会从还没开始的名称里去掉。

命名和规划完全离线，不读取、解析、匹配 SXRD 数据文件，不连接外部数据处理软件，也不检查同名目录是否已经存在。一次最多追加 1000 项，每项 1–100 次；追加后实验最多 10,000 项。

3. 现场快速记录

左侧选择待测样品，中间记录当前样品，右侧查看时间线。点击“专注当前样品”切换为单列，页头收紧，优先显示编号、主按钮和常用快记；滚动或输入时编号与主按钮仍可见。“队列与搜索”可查找样品，“更多操作”可打开时间线、未处理问题、临时样品和备样安排；“退出专注”恢复完整布局，顶栏保存状态与实验概览入口持续显示。

  1. 核对编号、状态和计划参数，点击“开始操作”。软件立即保存开始时间，全库同一时间只允许一个操作进行中。
  2. 原位和离位操作都能在现场页填写实验制度。还没开始时，改的是本次操作的计划，同一样品的其他制度各自保留。开始之后，页面固定显示开始时写下的制度。后来修改计划不会改掉这一次；若现场实际不同，在“实际参数”里填写实际实验制度。厚度、尺寸、制度或自定义值与开始时的计划不同时，现场页会直接列出计划值和实际值。 在“现场备注”中直接输入观察、变化和处理方式，停顿或离开输入框后自动保存。“已装样”“已调整位置”等常用按钮先保存自由备注，再创建独立的时间线记录，不覆盖备注。写错的时间线记录可以改正；取消不保存。保存不改变记录时间，也不改现场备注栏。改前的文字会标成“曾写”。回看的修改历史也写出这句，不再把改前文字重复放进原始数据。Excel 和 CSV 的事件表有“改前文字”列，没有改过时留空；再导入时这一列不写入样品。空白不能保存，也不能用它修改问题。队列搜索不到这句。“数据待检查”表示需要后续检查，不是数据合格的判定。
  3. 点击“记录问题”，可选择“装样待检查”“信号待检查”等模板，自动填入类别和内容，按需要补充后提交。未处理问题可打开明细、定位样品和标记已处理；标记只记录处理状态，不代表科学数据通过验收。回看里可以改正问题文字；取消不保存。保存不改变记录时间和处理状态，改前的文字仍留在这条问题里。回看、实验概览和 HTML 报告会写出“曾写”以及这些改前文字；没有改过时不写。现场时间线也会写出这句，并可以在那里改正问题文字。Excel 和 CSV 的“问题记录”写出同一句。队列搜索不到这句。空白不能保存，也不能用它修改备注。
  4. “添加图片”会复制 PNG、JPEG、WebP 或 GIF 到本地数据目录。单张不超过 10 MB。已经加上的图片可以移除；取消不删除。移除只拿掉这一张，不改起止时间，也不改开始时的计划。图片文件名可以在队列、测量计划、样品组、回看和全库搜索里找到，现场队列和回看也会写出这些名称。回看可以打开查看图片，打开和关闭都不改记录。移除后不再出现。备注和移除记录不因此变成可搜内容。
  5. 展开“实际参数与数据文件”，修改实际名称、厚度、宽度、高度或实验条件，补充仪器实际文件名、扫描编号及路径。实际文件名和扫描编号可以复制；含有路径或特殊字符的文件引用请在文本中手动选择并复制。复制不会改记录。实际参数初始沿用计划，不代表独立测量结果；已有记录保留开始时的计划和现场修改历史。

  7. 全部计划项结束、跳过或中断后，右上角出现“导出本次报告”。也可随时在“回看导出”生成当前实验报告，未记录的信息会在报告中列出。

键盘可以用 Tab 移动焦点、Enter 或空格操作按钮、Esc 关闭对话框。问题或时间线记录填写完后用 Ctrl + Enter 快速提交。 Ctrl + 1 / 2 / 3 切换规划、现场与回看页；切换前保存当前输入，对话框打开时不会切换页面。 Ctrl + K 打开实验库；继续输入则按样品编号、样品名、文件夹名、实验名、制度、批次、制备字段、扫描编号和文件引用搜索，不搜索备注和自定义值。方向键移动，回车打开。 Ctrl + / 打开快捷键表。现场队列按住序号拖动，或在序号上按 Alt + 上/下方向键调整完整顺序；筛选隐藏的项仍留在原来的相对位置。已预留的文件夹名不因调序改变。现场在非输入区域按 Alt + 左/右方向键，按完整排序选中相邻操作；搜索、筛选和专注模式都不改变这个顺序。它只选中，不开始、不完成、不调序。输入框、对话框、菜单或正在保存时不会切换，到队列两端后停住。

在非编辑区域按 F8 可开始或完成当前操作。输入框、文本框、选项框、可编辑文字、中文输入法组合输入、打开的弹窗、修饰键和重复按键不会触发 F8；有其他操作进行中时不能开始新操作。主要按钮保留至少 54 像素高度和 450 毫秒连续点击保护。

取消问题或时间线记录弹窗后，同一窗口内再次打开会保留类别、模板和文字；未提交草稿不写入数据库，退出或崩溃后不恢复。已提交记录失败时保留固定目标、内容和同一请求，点击“重试此记录”或重试保存后继续。提交中不能取消或关闭，真正保存成功才清除草稿。时间弹窗始终显示打开时的目标编号，原始点击时间和开始时计划仍保留。

当前样品右侧显示本次用时，由已记录的起止时间计算，跨日与重新打开软件后仍可查看；未知时间显示为空。页首进度按完成的计划操作统计，跳过与中断单独列出。

起止时间用于和仪器数据大致对应。精确时间仍查看仪器文件。软件记录完整日期，跨午夜不会把结束时间误认为早于开始时间。

完成进度为已完成操作数 / 全部计划操作数，跳过和中断单独列出。未启用备样不计入；重测增加计划操作数。

5. 从旧表导入，导出实验记录

回看页可按时间不完整、文件关联未补充、未处理问题筛出待核对的记录，清除筛选后恢复全部计划。预期文件夹名显示在样品信息下；实际文件栏没有引用时显示“未关联”，并可在这里填写文件名、扫描编号或文件引用。填写只写入这条已经开始的记录，不改起止时间，也不给还没开始的计划补一条记录。三项都空着不会保存。已经写过的文件名、扫描编号或文件引用也可以在这里修改；取消不保存，三项都清空也不会保存。已经开始的记录也可以在回看里修改现场备注；取消不保存。这条备注可以在回看里搜到，现场队列搜索不到。还没开始的计划不能在这里写备注。已经开始的记录也可以修改实际厚度、宽度、高度和单位；取消不保存，也不会改开始时的尺寸或起止时间。没填的高度保持空白。还没开始的计划没有这个入口。已经开始的记录也可以在回看里修改实际样品名、实验方式和制备试剂；取消不保存，清空后保持空白，也不会改开始时的计划、厚度或起止时间。还没开始的计划没有这个入口。回看可以只看“实际已改”的记录，并与状态、搜索叠加；它只隐藏其他行。只改备注、文件引用或当前计划不会出现。没有这种记录时不显示这个筛选。若厚度、尺寸、制度或自定义值与开始时的计划不同，编号下会列出计划值和实际值；扫描编号和文件引用不写进这张对照。操作记录旁的已记录用时只累加起止都已写下的间隔，缺时间的次数单独标出，不按当前时间估算。未开始的计划不会被当作缺少实际记录，也不会生成这种对照。导出始终包含当前实验全部记录；报告在确有不同时写出同一对照，并写上同一口径的已记录用时。Excel 和 CSV 另有“实际与开始时不同”列：确有不同时写出开始值和实际值，没有差异、只改备注或文件引用、以及还没开始的操作留空。再导入时这一列不写入样品，也不改已有记录。待核对清单按样品列出时间不完整、文件未关联和挂到操作上的未处理问题；还没开始的计划不会因为没有记录而出现在清单里。Excel 和 CSV 的操作记录有同一口径的“待核对”列，没有缺项时该列留空。同一份操作记录还有“用时”列：起止都已写下时写出间隔，缺时间时写“未计入”，还没开始则留空。再导入时“用时”不写入样品。把导出的 CSV 再导入时，只读取样品组；这一列不会变成样品字段，操作行也不会生成实际记录。

导入

“导入表格”支持 XLSX、UTF-8 CSV、TSV；XLSX 读取第一张工作表。也可在 Excel 或飞书中一起复制表头和多行记录，点击“粘贴多行”。一次最多 10,000 行、300 列，文件不超过 20 MB。软件导出的完整 CSV 列数会超过旧的 100 列上限，现在可以整份重新导入。

先预览和核对字段映射，再确认导入。“数量”映射到准备数量；“已完成”和旧“实验时间”只作为历史信息。空白时间仍为空，导入后不会生成操作或自动安排全部准备样品。其余列可作为自定义文本字段保留，再按需要设置单位和类型。软件导出的 XLSX 含参数定义，重新导入规划时可以保留自定义字段类型、单位和空值。

软件包“示例表格”中有旧格式合成演示“旧格式演示.tsv”以及纯演示“演示规划.tsv”。旧表未补造时间。

导出

在“回看导出”搜索名称、编号、样品 ID、文件名或备注，也可按待测、进行中、已完成、已跳过或已中断筛选。状态筛选可与搜索和待核对条件一起用，清除后恢复全部操作。筛选不改变导出内容。核对问题和历史。粘贴完整记录 ID 只留下对应的那一条操作。每条操作显示稳定样品 ID，可复制样品 ID 和数据文件夹名。已经开始的操作复制开始时的文件夹名。实际文件名和扫描编号也可以复制。复制不会改记录。用“一键生成实验报告”得到可阅读的 PDF / HTML 和完整结构化记录；也可选择 Excel、CSV 或 JSON。搜索与“只看有问题”不会删减导出；导出包含当前实验的全部规划与操作。

格式 内容与用途
Excel（XLSX） 规划、操作记录、时间线与修改历史、附件清单、参数定义。含起止及原始时间、计划/实际参数、单位、问题和文件引用。样品与扫描编号为文本，前导零保留。
CSV UTF-8，按“记录类型”区分样品组、操作、事件、附件，含未安排样品及历史。空值为空字段；直接用 Excel 打开可能被自动识别为数字，查看前导零编号优先选 XLSX。
JSON LabRecord 格式版本 1，保留稳定 ID、字段定义、单位、null 和完整历史，便于后续数据处理。

修改单位或字段名称后，旧操作导出时仍使用当时的字段定义和单位，不自动换算。JSON 和表格用于数据交换；恢复软件中的全部数据使用下节的完整备份。

6. 保存、备份与恢复

所有数据保存在当前 Windows 用户的 %APPDATA%\LabRecord，数据库在 workspace\records.sqlite，现场图片在 workspace\attachments。具体路径可在“设置 → 保存与备份”查看，点击“打开数据目录”定位。

  • 正在保存：当前还有输入等待写入。切换页面、样品、开始/完成和正常关闭前会先保存。
  • 已保存到本机：当前修改已写入本地数据库。
  • 保存失败：输入保留在界面。检查磁盘空间或目录权限，再用“重试”保存；如果某项操作按钮失败，修正问题后重新点击该操作。失败输入未保存时，页面切换和关闭会保留当前界面。

每天首次打开或保存实验后创建一份完整自动备份；长时间运行也会检查日期。保留最近 10 份自动备份；手动备份和恢复前备份不自动清理。

  1. 手动备份：在“设置 → 保存与备份”点击“备份全部数据与附件”，选择文件位置，得到 .labrecord 完整备份。可复制到其他硬盘保存。
  2. 恢复：点击“恢复完整备份”，选择文件。软件先校验数据库、数据关联、文件清单与 SHA-256；校验通过后选择“恢复”。
  3. 切换前自动为当前全部数据制作 before-restore-*.labrecord，并保留旧工作目录。恢复失败时回到原目录；成功后检查实验、备注、时间和图片即可继续记录。
完整备份包含全部实验、修改历史和现场图片，展开内容最多 512 MB。仪器数据文件引用保存为路径；仪器原始文件仍在原位置，需要另行复制。软件更新时替换软件包，实验数据仍保留在用户数据目录。

Windows x64 便携程序未进行代码签名。系统如询问来源，应先核对收到的软件包和提供的 SHA-256。软件无需管理员权限。

7. 实验结束后一键生成报告

  1. 在“回看导出”点击“一键生成实验报告”，或在现场全部操作结束后点击“导出本次报告”。
  2. 选择保存位置。软件自动建立本实验的独立报告文件夹，不要求逐个选择格式，也不会覆盖之前的报告。
  3. 阅读 PDF 或 HTML，核对缺少的起止时间、数据文件关联和待处理问题。报告展示开始时的计划与实际记录；未知值显示未记录。
文件 用途
report.pdf 打印、分享和归档；包含尺寸、操作、问题、时间与历史。
report.html 双击离线阅读，图片已嵌入；可单独发送给他人。
records.json 完整实验实体和稳定 ID，保留单位、空值、原始时间及全部修改历史，供后续 agent 或数据处理读取。
README-agent.md 说明文件和字段含义、完成情况、待核对信息及读取顺序。
images 与 manifest.json 现场图片原文件及 SHA-256 清单，便于确认报告内容完整。

将整个报告文件夹交给后续 agent，先阅读 README-agent.md，再根据 records.json 核对明细。报告只是已保存实验记录的整理；尚未记录的时间、测量值和科学结论不会自动生成。报告用于阅读和分析，软件恢复仍使用 .labrecord 完整备份。

8. 通过 GitHub 私人仓库换电脑接续

云同步是可选功能。离线仍可完成规划、现场记录、报告和备份；联网后手动点击同步即可。同步包含全部实验、历史和现场图片，仪器原始文件仍需另行复制。

  1. 点击顶栏“云同步”。填写自己的私人仓库 你的账号/实验数据仓库；也可填写自己的 账号/私人仓库。软件每次验证仓库确为私人仓库。
  2. 已登录 GitHub CLI 的电脑可直接连接。其他电脑可登录 GitHub CLI，或填写 GitHub 细粒度访问令牌，仅授予选定私人仓库 Contents 读写权限。令牌加密保存在该电脑，未写入实验备份、报告或仓库。
  3. 本机修改保存后点击“同步实验记录”。新电脑连接同一仓库，第一次同步接收实验和图片，之后即可离线继续。
  4. 只有一端有变化时，软件自动判断上传或接收。两端分别修改时出现两项选择：“使用云端，本机留备份”或“使用本机，云端留历史”。先核对两边的实验与操作数量再选择。
接收前先为本机制作 before-cloud-*.labrecord 完整备份；上传不会删除旧快照。本机有进行中的操作时，需要先完成或中断才能接收云端。两份记录不会自动逐字段合并。

图片较多时自动分段上传，完整备份及展开内容上限 512 MiB。连接或传输失败保留本机数据，可联网后重试；不会把失败显示为同步完成。另一电脑需独立登录，同步不会迁移登录凭据。本机“已保存”与云端“同步完成”分别表示本地和云端状态。

9. 报告云端归档

连接私人库后，默认在生成报告时同时安排后台归档。报告先保存到本机，再上传 PDF、HTML、JSON、图片和 agent 说明；上传期间可继续现场记录。云同步页可关闭自动归档、重试、刷新云端报告、查看私人库目录或下载完整报告。

离线或失败保留待上传任务；启动、重新连接或同步时重试。任务绑定原仓库，更换仓库不会转移旧任务。本机已保存和云端已归档分别显示。每次导出保存为独立版本，下载时校验 SHA-256；大于 20 MiB 的文件分段保存并在下载时重组。单份报告上限 2 GiB。后续 agent 先读 README-agent.md 再核对 records.json。
