# LabRecord 0.7.1 · 录入更省心，现场更顺手

用于材料实验的中文 Windows 离线记录工具：规划样品、记录现场操作，一次导出可追溯报告。本版本整合了最新的规划、现场和回看流程改进。

## 使用体验

- **新建实验少一次返工。** 自动建议当天未占用的编号；手动输入重复编号时即时提示，并定位到编号框。
- **误关表单也能继续。** 添加样品时，已有输入会先保留，可选择“继续填写”或“放弃填写”；连续添加成功后，沿用参数不会反复触发退出提示。长按 Ctrl+Enter 和中文输入法组合输入不会重复添加。
- **添加和安排更直接。** 材料制备信息按需展开；安排样品默认 1 件，数量明确时可选择“全部安排”。
- **现场常用操作靠前。** 当前样品、快记、备注和文件夹集中展示，窄窗口中的复制按钮可以换行。
- **回看缺项可直接补充。** 从待核对清单打开对应的时间或文件窗口；取消不写入记录。测量计划支持一键清除筛选。
- **查找不再停在前八项。** 全库搜索显示结果数量，可展开更多结果，一键清除后回到实验库并保留键盘焦点。查看只选中目标，不自动开始操作。
- **项目首页更易读。** 新的 imagegen 概念主视觉，配合本版本真实程序的合成实验截图和三步上手说明。

## 下载与更新

下载附件 `LabRecord-0.7.1-Windows-x64.zip`，**完整解压到一个文件夹**，双击 `LabRecord.exe`。无需另装 Node.js、Python、Excel 或数据库。现有用户可先在设置中导出完整备份，再运行新版；原记录保存在当前 Windows 用户的数据目录中。

附件还包括 `SHA256SUMS.txt` 和 `delivery-manifest.json`，用于核对下载包与交付验证信息。程序目前尚未代码签名。

## 记录与兼容性

数据库和备份格式仍为 v1。修改记录不会改写开始时的计划快照或原始自动时间；未知时间和数量不会被补成零。仪器原始文件仍由用户单独管理，路径引用不代表文件上传。

表单的未保存输入保护仅适用于当前窗口，不提供退出或崩溃后的草稿恢复。报告整理已保存记录，不判定实验数据是否合格。测试使用合成实验和独立临时目录，不访问私人实验记录。
