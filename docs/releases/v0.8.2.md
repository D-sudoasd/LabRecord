# LabRecord 0.8.2 · 每一件自己的尺寸

用于材料实验的中文 Windows 离线记录工具。一组里的样品可以厚薄不同，尺寸在安排时按每一件填写。

## 使用体验

- **安排待测样品时填写每一件的厚、宽、高。** 添加样品并安排、启用备样用的是同一套格子。后面没改过的行可以用「后面也用这个尺寸」，保存后仍是每一件各记各的。
- **样品组不再编辑一套共用尺寸。** 以前没单独填过的样品，规划表仍写着原来的组尺寸。新安排的留空就是这一件还没量。
- **现场的实际尺寸不变。** 开始时记下当时的计划尺寸；后来改计划，不改已经开始的那一次。

数据库和备份格式仍为 v1。

另外：演示编号会找下一个空号；输入时快捷键不再抢走文字框；备份成功会清掉对话框里的旧错误；报告可以存到盘符或网络共享的根目录。连按 Esc 只收起「放弃填写」。一次改多件的测量制度时，没改过的字段仍按每一件原来的值。

## 下载

下载 `LabRecord-0.8.2-Windows-x64.zip`，完整解压后运行 `LabRecord.exe`。现有记录仍在当前 Windows 用户的数据目录中。
