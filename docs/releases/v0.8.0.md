# LabRecord 0.8.0 · 回到开始页，顺序自己排

用于材料实验的中文 Windows 离线记录工具。这一版不增加记录种类，只让已经会用的操作更好找、更好调。

## 使用体验

- **载入演示或打开实验后，可以回到开始页。** 左侧「开始页」、顶部实验列表和全库搜索里的「回到开始页」都回到同一处。已有实验留在列表里，可以直接再打开。
- **开始页在有进行中的操作时仍然看得到。** 返回只选中那一条，不另写时间。
- **自定义参数可以调整顺序。** 在实验设置里上移或下移，保存后按这个顺序填写。已经开始的操作仍保留开始时的字段和单位。

数据库和备份格式仍为 v1。

## 下载

下载 `LabRecord-0.8.0-Windows-x64.zip`，完整解压后运行 `LabRecord.exe`。现有记录仍在当前 Windows 用户的数据目录中。
