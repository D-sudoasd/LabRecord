# LabRecord 0.8.3 · 每一件自己的状态和备注

安排测试时，一组里的样品可以各自填写样品状态和备注。

## 使用体验

- **安排待测样品时填写每一件的样品状态。** 默认带上本组现在的状态，改一件不会改其他件。留空则记下本组现在的状态。
- **每一件可以单独写备注。** 留空则沿用样品组的计划备注。写了就只属于这一件。
- **已经安排的样品**可以在组内直接改自己的状态和备注。

数据库和备份格式仍为 v1。现场仍保留开始时记下的计划。

## 下载

下载 `LabRecord-0.8.3-Windows-x64.zip`，完整解压后运行 `LabRecord.exe`。现有记录仍在当前 Windows 用户的数据目录中。
